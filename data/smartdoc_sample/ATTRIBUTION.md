# SmartDoc 2015 — Challenge 1 sample dataset

The 9 JPEGs in `frames/` are individual video frames extracted from the
`sampleDataset.tar.gz` "train kit" for the SmartDoc 2015 – Challenge 1
competition (ICDAR 2015), downloaded from
https://zenodo.org/record/1230218 (files `datasheet001.avi`, `letter001.avi`,
`magazine001.avi`, background `background00`).

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0).

**Citation:**

> J. Chazalon, P. Gomez-Krämer, J.-M. Ogier, M. Rusiñol, F. Damecasa,
> D. Lisu, N. Journet, "SmartDoc 2015 Challenge 1: Smartphone Document
> Capture," *ICDAR 2015 Competitions*, 2015.

**What's included here:**

- `frames/*.jpg` — 3 frames sampled per video (early / middle / late), at
  roughly 10%, 50%, and 85% through each clip, at original 1920x1080
  resolution.
- `ground_truth.json` — the document quadrilateral corners for each selected
  frame, parsed directly from the dataset's own `*.gt.xml` annotation files
  (not derived from this project's code — an independent check).
- `ocr_ground_truth.json` — a small set of key phrases per frame that are
  confidently legible to a human eye, hand-transcribed while reviewing the
  frames. Not a full-page transcription — see `NOTES.md` for why.
- `results.json` — generated by `scripts/benchmark.py`; not committed by
  hand, regenerate with `uv run python scripts/benchmark.py`.

Only a 9-frame subset of the ~24,000-frame full dataset is used, chosen to
stay small and reviewable while covering three document types (datasheet,
letter, magazine) across each clip's range of motion blur.
